# ISEKAI

Mod Minecraft Java 1.20.1 basata su Minecraft Forge 47.4.28 e Java 17.

## Compilazione automatica
Ogni push sul branch `main` avvia GitHub Actions. Al termine della compilazione, il file JAR viene pubblicato come artifact chiamato `isekai-forge-1.20.1`.

Questa è la base tecnica iniziale: contiene registrazione del mod, materiali e blocchi Aether. Texture, modelli, ricette, generazione del mondo e sistemi di gioco verranno aggiunti nelle successive fasi.
